# 🤖 AI Skill Gap Navigator

An AI-powered career guidance application that analyzes a student's current skills, compares them with the skills required for a target job role, identifies skill gaps, generates a personalized learning roadmap, and provides AI-powered career advice using Google Gemini.

## 🎯 Project Overview

B.Tech students often have difficulty identifying which skills they need to develop for their desired job role.

The AI Skill Gap Navigator solves this problem by allowing students to:

- Select their target job role
- Rate their current technical skills
- Analyze skill gaps
- Identify the most important skills to improve
- Generate a personalized learning roadmap
- Receive AI-powered career guidance using Gemini

## ✨ Features

- 🎓 Student profile management
- 🎯 Multiple target job roles
- 💻 Skill self-assessment from 0–10
- 📊 Automated skill-gap analysis
- 🔥 Identification of high-priority skills
- 🗺️ Personalized learning roadmap
- 🤖 Gemini-powered AI Career Advisor
- 📚 Recommended learning order
- 💡 Project recommendations
- 🎤 Interview preparation suggestions
